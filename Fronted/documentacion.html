Bloques y Procedimientos

Los procedimientos inician con el identificador en mayúscula y el delimitador |: cerrando con :|.

Main |:
    # Instrucciones aquí
:|

Escritura y Asignación

Usa <w> para imprimir por consola y <- para asignar valores a variables.

x <- 10
 "El valor de x es" x

Reproducción Musical

El operador (:) permite enviar notas o listas de notas musicales a la partitura.

(:) E5
(:) {D5 C5 B4}
